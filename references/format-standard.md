# 川师学生会公文标准化 SOP

## 一、执行约束

- 以用户提供的《四川师范大学学生会公文排版格式标准（2026年版）》为格式依据；本文件固化其规则。不得混入其他公文模板的默认格式。用户另有要求时标明偏离项，不声称完全符合本标准。
- 固定顺序：收单定型 → 环境预检 → 样式制作 → 结构机检 → 同源导出 PDF → 逐页目检 → 纠错复检 → 成对交付。不得跳过检查直接交付。
- Word任务交付 `.docx + 同名.pdf`；Excel任务交付 `.xlsx + 同名.pdf`；同时要求两类时分别成对，基名加“_公文”“_表格”等内容后缀，避免PDF重名覆盖。PDF必须由最终可编辑文件经排版引擎导出，不另写一份近似PDF，不以截图代替原生内容。
- 原文存在对齐冲突：第1页“一、5”及第3页“三、4”写居中，第3页“三、3”写正文两端对齐。未获发布单位澄清前，采用“具体条款优先，并参照示例”的执行约定：普通正文及各级文中标题两端对齐，其他要素按下表。审查结论注明该约定，合格时写“按本SOP执行约定通过”；不把已固定的约定反复列为待确认，但用户不接受时须暂停相关定稿。它不是发布单位的正式解释，不得宣称无保留的完全符合。

## 二、固定格式参数

全篇默认黑色；所有阿拉伯数字、英文用 Times New Roman，字号随所在要素。中文字体必须按下表设置；重点强调句段改用黑体。除明确要求的空行外，段前、段后均设0，不额外插空行。

| 要素 | 中文字体与字号 | 行距、对齐及缩进 |
|---|---|---|
| 大标题 | 方正小标宋简体，二号 | 固定35磅，居中；回行保持词意完整，梯形或菱形排列 |
| 副标题 | 楷体_GB2312，小二 | 固定35磅，居中 |
| 时间、作者备注 | 楷体_GB2312，三号 | 固定28磅，居中；日期加全角括号在上，作者在下 |
| 一级标题 `一、` | 黑体，三号 | 固定28磅，首行缩进2字符，两端对齐 |
| 二级标题 `（一）` | 楷体_GB2312，三号 | 同一级标题 |
| 三级标题 `1.` | 仿宋_GB2312，三号 | 同一级标题；点号为半角 |
| 四级标题 `（1）` | 仿宋_GB2312，三号 | 同一级标题；括号为全角 |
| 正文、署名和成文日期 | 仿宋_GB2312，三号 | 固定28磅；正文首行缩进2字符、两端对齐；署名日期另按下文 |
| 图片说明 | 仿宋_GB2312，五号 | 固定12磅，图片正下方居中 |
| 表格标题 | 方正小标宋简体，二号 | 单倍，居中，仅下框线 |
| 表头 | 黑体，三号 | 单倍，居中，所有框线 |
| 表内正文 | 仿宋_GB2312，三号 | 单倍，居中，所有框线 |
| 表格落款 | 仿宋_GB2312，四号 | 单倍，靠右，仅上框线；写“主要责任组织（部门名称） 制”并代入真实名称 |
| 页码 | Times New Roman，四号 | `— 1 —`，长横线与数字间各一半角空格；奇数页右下、偶数页左下 |

- 页面：A4；页边距上3.7、下3.5、左2.8、右2.6厘米；页脚距纸张底端2.75厘米。按实际页序设置奇偶页，使用动态页码，核对分节和首尾页；不得任意关闭首页页码或每节重置。
- 字号换算：小一24、二号22、小二18、三号16、小三15、四号14、五号10.5磅。首行2字符应按字符设置，不用两个空格代替。
- 标题组：大标题接副标题或备注不空行，副标题接备注不空行；整个标题组结束后空1行接正文。标题独立时同样下空1行；不重复累计空行。
- 附件说明：正文下空1行，左空2字写“附件：名称”；多个写“附件：1. 名称”，点后空1格，顺序编号；名称末尾无标点，续行与名称首字对齐。附件另起页，第一行顶格“三号黑体”的“附件”及序号；第二行空行，第三行居中排附件标题，其余按相应正文或表格规则。
- 署名日期：正文结束后空2行；有附件说明时置于说明之后，不重复累计空行。组织全称在上、完整成文日期在下，组成靠右且内部居中的文字块。日期写“2026年1月1日”式，不补零；不以空格堆出位置。尾页确实放不下时，才可局部微调行距、字距，记录修改并重检，不全篇缩字号。
- 图片：嵌入型，放对应文字下方，必须配说明；以4:3或16:9为主，同类尺寸协调统一，不拉伸、不遮字、不伪造图片或徽标。
- 表格：整体居中；学院、学号、姓名、联系方式原则上不换行。跨页重复表头。按已核实的学院顺序、学生组织顺序及学号升序排序；不掌握组织顺序时列为待确认，不自造顺序，可先做不依赖它的工作。仅对同一分组内连续同值的组织信息适当合并；不得丢失记录、跨组误合并或破坏公式。复杂表单先调空间，确有换行风险的字段可适当缩字并登记例外。标题及落款的边框作用于整行容器，不给每个字或每个子格画线；Word表格标题可用对应宽度的段落下边框。原文未量化的微调不自造硬性阈值，须记录实际值并经目检验收。

## 三、Excel专用适配

以下是落实原文“根据Word版本要求作适当调整”的执行方法，不冒充原文新增硬性指标。

- 保留可编辑数据及公式；学号、电话按文本保留前导零和长数字。先排序再合并；核对记录数、唯一标识及汇总值，禁止因美观删数据。
- 按上表设置标题、表头、数据、落款的字号、字体、对齐、边框；混合中西文文本用富文本分段设置字体。公式输出若无法分别设中西文字体，调整字段布局或报告阻断，不默认为全篇同一种字体已合规。
- 设置A4、规定页边距和页脚距离、准确打印区域；表格在版心内水平居中，关闭默认打印网格线、行列标号。设置重复表头行，排除标题、落款等不应重复的行。
- 启用奇偶页不同页脚：奇数页右侧、偶数页左侧，动态页码、四号Times New Roman，显示为“— 页码 —”；关闭页脚随页面缩放。多工作表合成一个PDF时按最终打印顺序设置连续页号与奇偶位置。
- Excel没有Word的段落固定行距和单倍行距属性；用行高、列宽、垂直居中及打印预览实现相应版式。不得把“固定28磅行距”机械换成“28磅行高”。单元格字号以最终打印效果核对。
- 优先调整列宽和分页，保持打印字号；不默认“整表缩为一页”、自动缩小字号或任意改横向。确需横排时，按原文核对装订方向：单页码表头在订口一边，双页码表头在切口一边，页码位置与其他公文页一致；引擎不能实现时不得判通过。

## 四、条件要素与文字校核

- 策划、阶段方案及总结：具备封面、目录、正文；封面包含部门全称、阶段时间等标题信息，部门全称和完稿日期落款，以及校徽、会徽，校徽在左。封面标题可用小一号；落款按一级标题字体格式，可调小三或四号。缺少真实徽标时请求提供，不伪造。更新目录及页码后再导出。
- 总结：成果用简明表格及真实数据支撑，活动亮点数据加粗，表格整体居中。学校地名、部门、组织使用全称；除校级单位、组织外，名称可省略“四川师范大学”。
- 地点：使用“狮子山校区”；教室写“第七教学楼203室”式，成龙校区写“第一教学楼A区203室”式，教学楼序数为汉字、区名字母大写、“室”不省略。操场写“第一运动场”式；寝室按实际信息写学院、年级、管理单位、楼栋及寝室号，无特定信息时可只写管理单位。特殊场所写明校区及具体地点；狮子山办公室写“狮子山校区天朗气清二楼B27办公室”式。网络地点写“‘XX’微信公众号”“‘XX’活动QQ群”式；不凭格式示例编造实际地点。
- 参与人员：写“学校/学院/年级/组织/部门＋全体/部分＋同学”的实际组合；嘉宾用“单位＋职称＋姓名＋同志/老师/教授/男士/女士”，列于学生之前，按已核实的职级、部门顺序排序，不推测职务或称谓。
- 核对错字、语病、日期、星期、时间、地点、人名、全称、编号、附件对应和数据。中文语境用全角中文标点；时刻用半角冒号“12:30”；数字范围用长横线“20—30人”；不得全局替换而损坏编号、公式、网址或数据。
- 内部或保密资料：版心首行顶格三号黑体标注“内部资料/保密资料”，次行顶格小三号标可见范围，再空1行排标题；原文未明确范围行字体，沿用黑体作为执行约定。与附件首页标识重叠时核对示例并记录处理，未解决冲突不得自行宣称合规。保护原有可见范围，不额外对外传播。

## 五、审查纠错与交付门禁

1. **收单定型**：确认文种、输出类型、正文/表格/附件关系、实际署名日期、排序依据及必要素材。只追问会影响真实性或合规的缺项；其余采用本SOP。新建样式映射，修改文件则保留内容、数据、公式及有效结构。
2. **环境预检**：读取本环境可用的Word、Excel、PDF制作技能，遵从其工具要求。检查指定字体实际安装与字形覆盖，以及可编辑文件导出PDF的能力。字体名称写入文件不代表字体存在。仅生僻字、繁体字确实缺字时允许单字用同类字体替代并登记；不得整篇偷换字体。必要字体、素材或排版引擎缺失则标阻断，保留草稿并明确所缺条件。
3. **样式制作**：按要素套用固定样式，显式设置中文/西文字体、字号、颜色、段落、分页和边框；清除主题字体、直接格式、自动缩放和旧样式的冲突。只有原文明确允许的调整可作为例外，登记位置、依据、调整前后值及原因。
4. **结构机检**：用可用解析工具检查DOCX的全部节、样式和实际有效段落/run属性、表格、域、图片；检查XLSX的工作表、有效字体/富文本、边框、打印区域、重复表头、页脚、分页及公式计算结果。不能只查样式定义或抽查首个段落。用Python核算尺寸换算、记录数、排序、日期、汇总及公式结果，执行反算或独立对照。
5. **同源导出**：在实际排版引擎中更新页码、目录及公式后保存最终DOCX/XLSX；直接导出同名PDF。固定记录“源文件名及SHA-256/PDF文件名及SHA-256/导出引擎/PDF页数/字体检查结果”，两文件分别记哈希，不要求彼此相等；导出后只要源文件改变，即废止旧PDF和验收记录。
6. **逐页目检**：将最终PDF全部页面渲染成图逐页检查，并打开源文件打印预览对照。检查A4、实际字号字体、换行、空行、版心、标题形状、奇偶页码、附件起页、署名日期、横排装订方向、续表表头、边框、图注、缺字、截断、遮挡、空白页及异常缩放；核对所有打印工作表与全部记录均已纳入。检查PDF字体是否替换或缺失，不能凭文本提取或程序成功认定通过。
7. **纠错复检**：逐条记录“规则/位置/实际值或现象/应有值/修复/复检结果”，改源文件，再机检、重导出、重渲染。数据或公式变更重新核算；影响流式布局的修改重新检查全部页。未解决问题保留为失败或待确认，禁止用文字“已检查”代替证据。
8. **成对交付**：对下表各组中的每个适用要素填写“位置/应有值/实际值/证据/通过、失败、待确认或不适用”；不适用须写理由，不以整组一句“通过”代替逐项检查。有失败、待确认、必要字体缺失、未渲染页或PDF缺失时，不得宣布合规完成。可交付的仅标“待确认草稿”，仍须成对；无法导出PDF则明确未完成，不把单个源文件当成完整交付。全部适用项通过后，交付原文件及其对应PDF，附简短审查结论和已采用的规范解释/允许例外。

| 检查组 | 必核内容 |
|---|---|
| 页面与页码 | 每节/每打印页的纸型、边距、页脚距离、连续页号、奇偶位置 |
| 字体与段落 | 每类要素的有效中西文字体、字号、颜色、行距、缩进、空行、对齐 |
| 表格与数据 | 标题/表头/正文/落款、边框、续表、排序、合并、无损数据、计算 |
| 结构与素材 | 封面目录、附件、署名日期、图片说明、徽标、保密标识 |
| 文字与事实 | 全称、地点、参与人员、标点、日期时间、编号、真实数据与来源 |
| PDF与交付 | 同源最终版本、全部页目检、无字体替换/截断、文件成对及各自版本哈希记录 |

技术实现核对来源（仅用于字号换算及软件操作，不替代校内规范）：[WPS字号对照](https://www.wps.cn/learning/room/d/328977)、[Excel页面设置](https://support.microsoft.com/zh-cn/excel/page-setup)、[Excel重复标题行](https://support.microsoft.com/zh-cn/excel/repeat-specific-rows-or-columns-on-every-printed-page)。
